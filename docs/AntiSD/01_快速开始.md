## 1. 这个仓库在做什么

AntiSD **不是**一个新的网络结构，也不是多模态模型。它是一套 **数学推理 RL 训练算法**：

1. 用 **GRPO** 对可验证奖励（答案对/错）做序列级优势；
2. 用「同一模型 + 特权上下文 \(c\)」（组内正确解答 + 对错反馈）当 **self-teacher**；
3. 把 token 级信号 \(u_t = t_t - s_t\) 解释成条件 PMI，然后 **反号、用 JSD 形状 \(\varphi\)** 做成 AntiSD 优势，再加到 GRPO 上。

推理阶段就是普通 Causal LM：加载训练后的 `actor/hf`（或基座）生成 `\boxed{}` 答案。仓库 **没有**单独发布 AntiSD 微调权重。

输入：自然语言题目（脚本会补 `\boxed{}` 指令）。
输出：完整生成 + 最后一个 `\boxed{}` 内容；有 `ground_truth` 时用 `math-verify` 判对错。

想用训练框架做正式 val（vLLM rollout + 同一套 reward）：

```bash
export WANDB_API_KEY=dummy   # 仍会被脚本检查；可用离线
export WANDB_MODE=offline
export MODEL_PATH=Qwen/Qwen3-8B
# 在 launch 命令后追加（需改脚本或 EXTRA_HYDRA_ARGS）:
# trainer.val_only=True trainer.val_before_train=True
```

`user.yaml` 训练内评测是 `temperature=0.6, n=4`；论文正式数字是 **avg@32, T=0.7, top-p=0.95**。两者不要直接对比。

## 7. 训练（论文主路径）

必须先有 GPU、数据、基座权重、`WANDB_API_KEY`。

```bash
conda activate antisd
cd /home/user/Documents/agentic-rl-lab/algorithm/AntiSD
export WANDB_API_KEY=你的key
export MODEL_PATH=Qwen/Qwen3-8B          # 或本地目录
# export N_GPUS_PER_NODE=8
# export NNODES=1

bash recipe/antisd/run/qwen3-8b/antisd.sh   # 本文方法
# bash recipe/antisd/run/qwen3-8b/sd.sh     # 默认自蒸馏（对照）
# bash recipe/antisd/run/qwen3-8b/grpo.sh   # GRPO 基线
```

同样三件套还在：`qwen3-4b/`、`olmo3-instruct/`、`olmo3-think/`。

| 方法 | 脚本差异 | 论文对应 |
|---|---|---|
| AntiSD | `PRM_RENYI_SIGN=-1`（默认）+ Schmitt 门 | Algorithm 1 |
| SD | `PRM_RENYI_SIGN=+1`，且关掉门 | 默认自蒸馏 \(\delta_t=+u_t\) |
| GRPO | `ca_lambda=0`，不用 PRM | Eq. (2) 且 \(\lambda=0\) |

论文写 **200 on-policy steps**。当前 `launch_short.sh` 只设了 `trainer.total_epochs=1`（约 \(17000/32 \approx 531\) step），**没有** `total_training_steps=200`。要对齐论文：

```bash
export EXTRA_HYDRA_ARGS="trainer.total_training_steps=200"
bash recipe/antisd/run/qwen3-8b/antisd.sh
```

`EXTRA_HYDRA_ARGS` 已在 `launch_short.sh` / `launch_long.sh` 里解析；`grpo.sh` 没有这段，需要对 GRPO 手动加 Hydra 覆盖。

多机：先自己起 Ray，再

```bash
export NNODES=4
export RAY_ADDRESS=ray://<head>:10001
```

## 8. 建议的上手顺序

1. `conda_env_setup.sh` + `python -c "import verl,torch; print(torch.cuda.is_available())"`
2. `prepare_antisd.sh`，确认 `datasets/math/train.parquet` 存在
3. `inference_math.py` 跑通一道题（可 CPU，但会很慢）
4. 读 `recipe/antisd/README.md` 和 `dp_actor.py` 的 `jsd_unbiased` 分支
5. 单节点、小模型（Qwen3-4B）开 5 个 warmup step 看 W&B 是否出 `teacher_perp` / `jsd` 指标
6. 再考虑 200-step 正式复现（8×80GB 级 GPU）

硬件与数据集清单见同目录 `02_模型与训练需求.md`；公式与代码逐步对应见 `03_论文与代码对应关系.md`。

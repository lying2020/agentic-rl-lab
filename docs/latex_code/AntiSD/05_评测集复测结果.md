## 为什么低、为什么不能当复现失败

1. **模型不同**：Qwen3-4B ≠ Qwen3-4B-Instruct-2507。后者是论文基座，AIME 基线就高一截。  
2. **协议不同**：1 次采样 vs avg@32；4k token 截断 vs 32K。AIME 长推理会被截断。  
3. **没训 AntiSD**：测的是本地基座，不是论文 checkpoint。  
4. Minerva 最接近（36.4 vs 43.4），因为题更短、截断少。

结论：评测管线（数据 → vLLM → `\boxed{}` → math-verify）已经在论文四套核心集上跑通。要对齐 Table 1，需要 Instruct-2507（或 8B）权重 + avg@32 + 更长生成，以及作者放出的 AntiSD ckpt。
